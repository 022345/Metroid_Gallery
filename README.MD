# Metroid_Gallery
I discovered Metroid by Smash Bros Ultimate and since then I've become a fan of the franchise. I know there is the Fandom webpage for metroid information. But **I want to make a webpage where people can have a simple entrypoint in the franchise** (as well as a web project XD). So, here I present: **METROID GALLERY!** (on development).
